Локальная полная проверка

Эти команды заново проверят политику Cosign, provenance, доказательства и воспроизводимую сборку из чистого checkout.

git clone https://github.com/metalagman/webappsec
cd webappsec
git checkout <tag> && npm ci && npm run tools:signing
npm run verify:release -- --release <tag> --rebuild
